## Atividade - Calculadora de Média Escolar

### Objetivo

Desenvolver uma aplicação flutter capaz de receber o nome e três notas de um aluno, calcular sua média e apresentar a situação escolar 


### Conceitos 

- MaterialApp
- Scaffold
- StatefulWidget
- TextField
- TextEditingController
- ElevatedButton
- OutlineButton
- SetState
- Variáveis
- Conversão de texto para números
- Condicionais
- Funções
- Validação de campos
- SnackBar
